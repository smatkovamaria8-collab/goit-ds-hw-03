## GoIT: Homework 8

In this homework, the task was to work with MongoDB and Web Scraping using Python:

- Create a main.py script using the PyMongo library to perform full CRUD operations on a database containing cat records (managing their name, age, and features).

- Scrape data from the Quotes to Scrape website (scraping.py) to collect all quotes and author details, saving them into structured quotes.json and authors.json files. Set up a cloud database using MongoDB Atlas, create authors and quotes collections, and successfully import the scraped JSON data into them.

Technology used - Python, PyMongo, Beautiful Soup, MongoDB Atlas
